# 报告模板

两套模板：**A. 评估一个方向**，**B. 找方向（多个候选对比）**。
文件名建议：`momentum-report-<方向英文短名>-<YYYYMMDD>.md`。所有数字都要能追溯到脚本输出、文章快照或带链接的网页来源；拿不到的就写"未核实"，不要编。

---

## A. 评估一个方向

```markdown

> 评估日期：<YYYY-MM-DD> ｜ 数据：ICLR 2017–2026（<实时计算 / 预计算快照 / 文章快照>）+ arXiv 近 <N> 个月 ｜ 可信度：<高/中/低>

## 一句话结论

**建议**：<冲 / 换个切口再冲 / 先投低一档 / 暂不建议>，推荐投稿档位 <T1/T2/T3 + 具体会议>。
```
